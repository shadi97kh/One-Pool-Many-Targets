# GEM bio workshop: submission 101

This folder is the standalone September 7, 2026 workshop experiment snapshot for
*One pool, many targets*. It contains the experiment source, saved results,
figures, frozen extension configurations, acquisition ledger and original verifier.
Start with [the submission figure map](FIGURE_MAP.md).

The 154 historical files are copied byte for byte from GEM commit
`bd7850d3cac09b9564ea4b394fbdad111d399f3e`, the last workshop commit before the
AISTATS additions. The uploaded submission's extracted text is identical to the
saved workshop paper. [EXTRACTION_MANIFEST.json](EXTRACTION_MANIFEST.json) records
the source revision, manuscript fingerprints and a SHA256 for every historical file.

## Separation from AISTATS

This snapshot includes the original bisection solver and the 200-step bisection
compression experiment. Later GEM edits changed those shared files to use the
Newton solver in `src/onepool`. Those changes are not part of submission 101.
AISTATS calibration/dependence experiments, Newton integration, GPU benchmarks,
affinity-head pretraining, buffer titration, and L0/L1/L2/L6 studies remain in GEM.
No AISTATS package or parent-directory import is needed here.

The source GEM working tree retains its shared files because the active AISTATS
work depends on them. This folder is a frozen copy, rather than a relocation of
those dependencies. The original historical [README.md](README.md),
[MANIFEST.json](MANIFEST.json), and saved verification results are preserved;
their dates, older figure descriptions and counts describe earlier builds.
Use the new extraction manifest for this package's file integrity.

## Verify and redraw

From this folder, verify the export without installing scientific dependencies:

```bash
python3 verify_snapshot.py
```

Python 3.13 was used for the workshop. The scientific package versions are in
[requirements-workshop.txt](requirements-workshop.txt), taken from the historical
manifest; the complete historical environment remains in `MANIFEST.json`.

```bash
python3 -m pip install -r requirements-workshop.txt
PYTHONPATH=src OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python3 -m riscpool.checks
python3 scripts/make_figures.py
python3 scripts/make_px_figures.py
```

Plotting uses the saved result files, so no raw-data downloads are needed.
The two plotting commands generate all 12 numerical plots; Figure 4's supplied
workflow artwork is retained as an asset. Redrawing PDFs may change PDF metadata.
Run regeneration in a copy if you want to retain byte-identical archive files.

## Re-run experiments

Raw downloads, derived data caches and third-party literature were excluded from
the original Git snapshot. They are also excluded here; this is not an offline
raw-data bundle. The acquisition scripts and `data/PROVENANCE.json` identify them.
The historical driver runs the base study, and the extension scripts must be run
separately in the following order. These commands write new results, so use a
working copy when comparing against the archived recordings.

```bash
python3 scripts/run_all.py --list
python3 scripts/run_all.py --no-verify
python3 scripts/run_px_audit.py
python3 scripts/run_pxa_affinity.py
python3 scripts/run_pxb_approx.py
python3 scripts/run_pxb_audit.py
python3 scripts/make_figures.py
python3 scripts/make_px_figures.py
python3 scripts/make_summary.py
python3 verify.py
```

The archived study does not establish additional predictive value from coupling,
and its compression method is accurate without a measured speed-up. Historical
methods and negative results have been preserved. The later positivity-preserving
directional-gradient correction belongs to the subsequent GEM revision; the
original additive-perturbation diagnostic is not an updated validation claim.

## Validation of this extraction

All 154 historical files matched the selected Git tree. All 12 numerical plot
PNGs regenerated byte for byte, with zero skipped panels. The original solver
suite passed (conservation residual about `4.263e-14`, worst gradient error about
`1.074e-7`). The manuscript generator produced 235 numeric macros, and every
referenced figure resolved inside this folder. See [VALIDATION.json](VALIDATION.json).
Full dataset acquisition and all historical experiment runs were not repeated.

Manuscript PDFs and generated TeX remain local, following GEM's publication layout.
The existing `scripts/make_paper.py` and `scripts/make_bib.py` remain available to
audit how results feed the manuscript; they were already tracked in the workshop.
